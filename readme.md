# BANDLINK V1
Primera versión web funcional y responsive.

Incluye inicio futurista, conciertos demo, músicos en línea, Bandlink Match, perfil y navegación interactiva.

Los conciertos son demostrativos. No vende entradas ni procesa pagos.

Abre `index.html` en un navegador.

Siguiente fase: autenticación, base de datos, publicaciones reales, moderación, chat, videollamadas y fuentes autorizadas de conciertos.
